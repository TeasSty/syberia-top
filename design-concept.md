# Design concept — ST • Сибирия Топ

## Client / project

- Name: ST • Сибирия Топ (эстетик-туры, походы в горы)
- Date: 2026-11-27
- Niche: aesthetic hiking / travel club — Siberia author routes + travel shooting + trail cuisine (Irkutsk)
- Concept-ID: 2026-11-27-st-syberia-chrome-magazine-v1
- Composition-archetype: magazine-spread
- Forbidden-for-this-niche: quiet-luxury black/cream/gold; cream+#F4F1EA+terracotta+serif expedition journal; teal Ice Axe clone; purple gradients; hero+3 feature cards; Inter/Roboto/Arial defaults; soft boutique that fights chrome logo
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Rituals: VK inquiry → packing list → multi-day trail → golden-hour frames → camp dinner → gallery after
- Materials: chrome brand mark, cracked clay/earth, tent fabric, backpacks, trail cookware, pine, snow crust
- Places / light: Altai–Sayan–Baikal ridges; tent-mouth golden hour; cold blue peaks vs warm clay ground
- Vernacular: эстетик-тур, выезд, авторский маршрут, travel-съёмка, клуб
- Sensory: cold air + warm light, pine/smoke, grit under boots, metal mark against living ground

## Unique thesis

1. Mood: sculptural outdoor — chrome brand stands on living Siberian ground, not soft luxury paper.
2. Type rationale: heavy geometric display (Bricolage Grotesque) echoes thick 3D wordmark weight; Public Sans for itinerary UI — no oversized editorial serif vs metal logo.
3. Palette logic: chrome silver, cracked clay, sunset ochre, pine, ridge blue, near-black ink — from cover + VK photos, not luxury moodboard.
4. Composition: magazine-spread — chrome SYBERIA TOP as masthead/hero-signal on full-bleed place photo; below, editorial plates (routes, gallery, days) on clay ground.
5. Motion: slow image drift, one chrome-mark settle, section plate fades; 2–3 purposeful moves only.
6. Main gesture: «марка из хрома стоит в Сибири» — VK cover continued as web masthead.

## Anti-clone checklist

- [x] Carryover: not salon/chip/furniture palettes or archetypes from recent Desktop projects
- [x] Benchmark clone: Ice Axe craft (photo scale, pacing) only — not teal, structure, or identity
- [x] AI clusters: no purple gradient / cream+#F4F1EA+terracotta / broadsheet / dark SaaS / hero+3 cards
- [x] Brand test: logo off still reads as Siberia aesthetic hiking club (tent, ridge, clay, routes)

## Palette + type

- Palette:
  - `--chrome`: `#C8CCD2` (logo metal)
  - `--clay`: `#6B4E3D` (cracked earth cover)
  - `--ochre`: `#C4783A` (sunset / tent warm)
